# 🌱 Plant Disease Detection System

An AI-powered web application that detects plant diseases from leaf images using Deep Learning (CNN) and provides clear, farmer-friendly disease information.

---

## 📌 Overview

Early detection of plant diseases is crucial for preventing crop loss and improving agricultural productivity.  
This project uses a **Convolutional Neural Network (CNN)** to classify plant leaf images and identify diseases with a confidence score through a simple and intuitive web interface.

---

## 🚀 Features

- 🌿 Upload plant leaf images for analysis  
- 🧠 CNN-based disease classification  
- 📊 Confidence score for each prediction  
- 🖥️ Clean and responsive web interface  
- ⚠️ Error handling for invalid or missing inputs
