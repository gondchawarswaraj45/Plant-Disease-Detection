About This Project

This project uses Deep Learning (CNN) to detect plant diseases from leaf images. The trained model predicts the disease class, and Google Gemini AI provides human-readable explanations and treatment guidance.

  • Dataset: PlantVillage + Sugarcane dataset
  • Model: CNN (TensorFlow/Keras)
  • Backend: Flask
  • AI Explanation: Gemini API

Designed for farmers, students, and agricultural researchers.
